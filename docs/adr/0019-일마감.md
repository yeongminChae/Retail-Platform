# ADR-0019 점포 마감은 전 POS 마감 후에만 하고 마감 요약으로 ERP 수신을 검증한다

- 상태: 결정
- 날짜: 2026-11-18
- 관련 시스템: POS_APP, ERP

## 맥락
- 영업일은 점포 단위로 "점포 마감 → 다음 영업일 개시" 사건으로 전환한다 (ADR-0018). 마감을 하지 않은 경우의 규칙과 일배치 시점은 일마감 설계로 미뤘다.
- ERP는 사용 중 기기 목록으로 마감 누락을 판단한다 (ADR-0011). 판매 결과는 아웃박스로 건별 전송한다 (ADR-0014).
- 마감은 감사 로그 대상 민감 작업이다 (standards.md).
- 이 ADR은 시스템 간에 걸치는 부분만 정한다. 계산원 시재 입력 · 마감 화면 등 POS_APP 안에서 끝나는 것은 POS_APP 레포에서 정한다.

## 선택지
| 항목 | 선택지 | 장점 | 단점 |
|---|---|---|---|
| POS 마감과 점포 마감 | 전 POS 마감 후 점포 마감 (관리자 강제 마감 허용) | 마감된 판매의 영업일 귀속이 명확 | 고장 단말은 관리자 개입 필요 |
| | POS 마감과 무관하게 점포 마감 | 빠름 | 미마감 POS 판매의 귀속이 모호 |
| 미마감 상태로 다음 날 | 개시 차단, 관리자 마감 후 개시 | 시재 미확인 마감이 없음 | 아침에 관리자 조치 필요 |
| | 자동 마감 | 편함 | 시재 확인 없이 마감돼 현금 차액 추적이 어려움 |
| 마감 결과 전송 | 건별 판매 + 마감 요약 | ERP가 건별 합계와 요약을 비교해 누락 탐지 | 전송 항목 추가 |
| | 건별 판매만 | 단순 | 누락을 알 방법이 없음 |

## 결정
- **점포 마감은 사용 중인 POS가 모두 마감된 뒤에만** 할 수 있다. 마감하지 못한 POS는 매장 관리자가 **강제 마감**할 수 있고, 마감 · 강제 마감은 감사 로그를 남긴다.
- **이전 영업일이 마감되지 않았으면 다음 영업일 개시를 막는다.** 매장 관리자가 이전 영업일을 마감(강제 마감 포함)한 뒤 개시한다. 자동 마감은 하지 않는다.
- **일배치는 점포 마감을 계기로 실행한다** (시각 기준 아님). 상세는 ADR-0020.
- **마감 요약 전송:** POS 마감 · 점포 마감 때 마감 요약을 아웃박스(ADR-0014)로 ERP에 보낸다.
  - 요약 항목: 건수, 판매 · 반품 합계, 결제수단별 합계, 과세 합계 · 공급가액 · 부가세 · 면세 합계, 시재 차액, 이상거래 건수.
  - ERP는 그 영업일에 받은 건별 판매의 합이 마감 요약과 같을 때 그 영업일을 **수신 완료**로 본다. 다르면 누락 · 중복으로 보고 알린다.

## 대가와 후속 작업
- 마감 요약이 건별 판매보다 먼저 도착할 수 있다 (아웃박스 전송 순서 미보장, ADR-0014). ERP는 요약 도착 후 일정 시간 동안 건별 판매를 기다렸다가 불일치를 판단한다. 대기 시간은 미정.
- 불일치를 발견했을 때 점포 서버에 재전송을 요청하는 경로는 없다 (요청 방향은 점포 → 본사, ADR-0013). 아웃박스 재시도로 해소되지 않는 불일치의 처리 절차는 대사 설계에서 정한다.
- 마감 이후 취소 · 정정(마감 재오픈)을 허용할지는 미정.
- 계산원 시재 입력 방식 · POS 마감 화면은 POS_APP 레포에서 정한다.
