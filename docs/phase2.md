## 각 시스템이 받은 과제

Payment 설계에서 다른 시스템에 생긴 일은 각 ADR의 "대가와 후속 작업"에 있다. 모아 보면 다음과 같다.

| 시스템 | 과제 | 근거 |
|---|---|---|
| Retail-POS | 거래번호 순번 규칙, 운영 전용 POS 기동 거부 · 마감 제외, 영수증번호, `pos-payment-sdk`로 카드 읽기 · 공개키 캐시 | ADR-0045, 0046, 0047, 0050 |
| Retail-ERP | 결제 상태 수신 · 거래 키로 묶어 보기, 운영 요청 화면 · 대기 목록 · 종료 신호 수신, 가맹점 · 터미널 · 교차 취소 입력과 연결표 API, 매입 제외 목록 API · 매입 결과 수신 · 정산 대사 | ADR-0025, 0040, 0047, 0048, 0049 |
| 이 레포 `contracts/` | 위 API들의 계약 (시스템 간 인증 · 계약 버전 규칙 포함) | ADR-0025, 0043 |
