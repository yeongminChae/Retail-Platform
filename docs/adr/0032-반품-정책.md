# ADR-0032 반품은 7일 이내 전 매장 통일, 재판매 가격은 진입 경로로 정하고 신선 · 조리 식품은 단순 변심 반품 불가

- 상태: 결정
- 날짜: 2026-11-23
- 관련 시스템: POS_APP, ERP

## 맥락
- 반품은 고객센터 POS에서만 하며, 고객센터 POS는 재판매도 한다 (ADR-0031).
- 반품은 영수증 전체 단위만 지원한다 (POS_APP 결정 Q5). Payment Server에 부분 취소가 없고 부가세는 판매 단위로 계산한다 (ADR-0016).
- 따라서 일부만 반품하려면 **전체 반품 후 나머지 상품을 다시 판매**해야 한다. 이때 오늘 가격을 받으면 원거래 때 할인 · 가격 변동분만큼 고객이 손해를 본다.
- 판매 라인에는 판매 시점 가격이 스냅샷된다 (ADR-0007). 할인 · 행사가 자체는 v1 범위 밖이지만, 가격 변동만으로도 같은 문제가 생긴다.

## 선택지
| 항목 | 선택지 | 장점 | 단점 |
|---|---|---|---|
| 재판매 가격 | 진입 경로로 구분 (반품 메뉴 → 원거래 가격 / 일반 판매 → 오늘 가격) | 부분 반품 대용에서 고객 손해 없음. 새 구매는 판매 시점 가격 원칙 유지 | 판매 유형이 하나 늘어남 |
| | 항상 오늘 가격 | 단순 | 부분 반품 대용에서 고객 손해 |
| 반품 기한 | 전 매장 통일 7일 | 단순, 고객 안내 쉬움 | 상품별 차이 없음 (신선 · 조리 식품은 별도 속성으로 처리) |
| | 상품 분류별 기한 | 세밀 | 관리 · 안내 복잡 |
| 신선 · 조리 식품 | 단순 변심 반품 불가 + 하자 시 예외 | 정책 명확, 하자 클레임 대응 가능 | 예외 판단을 담당자가 함 |
| | 무조건 불가 | 단순 | 하자 상품 클레임 |

## 결정
- **재판매 가격은 진입 경로로 정한다.**
  - **반품 메뉴에서 진입한 재판매(원거래 연결 재판매):** 원거래 판매 라인의 가격(판매일 가격)을 그대로 쓴다. 재판매 판매에 원거래 번호를 연결해 ERP로 보낸다.
  - **일반 판매로 진입:** 오늘 가격(판매 시점 가격)을 쓴다 (ADR-0007).
- **반품 기한은 전 매장 통일 7일**이다. 원거래 영업일로부터 7일째 영업일까지 반품할 수 있다 (예: 11/20 영업일 판매 → 11/27 영업일까지). 값은 ERP 기준정보(전 매장 공통 값 하나)로 두고 기준정보 배포(ADR-0020)로 내려준다. 고객센터 POS가 반품 요청 시 검사한다.
- **신선 · 조리 식품은 단순 변심 반품 불가**다. ERP 상품 마스터에 **단순 변심 반품 불가** 속성을 두고, 고객센터 POS는 그 상품이 포함된 반품을 막는다.
  - **하자 예외:** 상품 하자(예: 변질)면 처리 담당자가 사유를 입력하고 반품을 진행할 수 있다. 사유는 반품 판매 · 감사 로그에 남고 담당자가 책임진다 (ADR-0031).
  - 반품 불가 상품이 섞인 영수증에서 다른 상품만 반품하려면 전체 반품 후 원거래 연결 재판매로 처리한다.

## 대가와 후속 작업
- 반품 기한 7일이 상용 매장 관행과 맞는지, 오프라인 매장 반품에 법적 기준이 있는지는 **확인하지 않았다** (오프라인 반품은 매장 정책이라는 것은 **가정**).
- "7일째 영업일까지"의 기준(영업일 vs 판매 확정 일시 + 7×24시간)은 이 ADR에서 영업일로 정했다. 운영상 바꿀 필요가 생기면 새 ADR로 정한다.
- 원거래 연결 재판매에서 원거래의 일부 상품만 재판매할 수 있게 하는 화면 흐름, 수량 검증(원거래 수량 초과 불가)은 POS_APP 레포에서 정한다.
- 단순 변심 반품 불가 대상 상품 분류 목록은 ERP 상품 설계에서 정한다.
