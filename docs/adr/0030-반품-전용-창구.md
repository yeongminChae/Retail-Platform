# ADR-0030 반품은 반품 전용 창구에서만 하고 처리 담당자가 책임진다

- 상태: 대체됨 (ADR-0031)
- 날짜: 2026-11-23
- 관련 시스템: POS_APP, ERP

## 맥락
- standards.md는 권한 항목에서 "반품은 관리자 승인 필요"로 정했다.
- 계산대 PIN을 전 역할 4자리로 정하면서(ADR-0029), 관리자 PIN 하나로 현금이 나가는 반품을 승인하는 구조의 위험이 논의됐다.
- POS 기기는 ERP에 유형과 함께 등록한다 (ADR-0011).

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| 아무 계산대에서나 반품 + 관리자 PIN 승인 | 어디서든 처리 | 관리자 PIN 노출 시 가짜 반품 위험. 계산대마다 관리자 호출 |
| 반품 전용 창구에서만 + 처리 담당자 책임 | 반품 경로가 한정되어 통제 · 추적이 쉬움. 관리자 호출 불필요 | 반품 고객이 전용 창구로 가야 함 |

## 결정
- **반품은 반품 전용 창구로 지정된 POS에서만** 할 수 있다. ERP의 POS 기기 등록 항목에 **반품 가능 여부**를 추가하고(ADR-0011 확장), 점포 서버는 반품 가능 기기가 아닌 POS의 반품 요청을 거부한다.
- 반품을 처리할 때 **처리 담당자 사번**을 기록한다. 반품 판매와 감사 로그에 남는다.
- **허위 반품이면 그 건의 처리 담당자가 책임진다.** 관리자 승인은 두지 않는다. standards.md의 "반품은 관리자 승인 필요"는 이 결정으로 바뀐다.

## 대가와 후속 작업
- 반품 창구 담당자를 특정 역할로 제한할지, 그 창구에 로그인한 계산원 누구나 처리할지는 미정 (ERP 권한 설계).
- 책임 소재 판단 · 사후 조치는 운영 절차로 둔다.
- 반품 전용 창구 화면 · 원거래 조회 흐름은 POS_APP 레포에서 정한다.
