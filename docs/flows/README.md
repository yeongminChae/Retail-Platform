# end-to-end 업무 흐름

시스템을 넘나드는 업무 흐름을 하나에 한 파일로 정리한다. 각 흐름은 `e2e/` 시나리오 테스트와 1:1로 대응시킨다.

| 흐름 | 파일 | 상태 |
|---|---|---|
| 입고 (발주 → 입고 → 재고 원장) | `inbound.md` | 미작성 |
| 판매 · 결제 (장바구니 → 현금/카드 복합결제 → 판매 확정 → 재고) | `sale.md` | 결제 부분 결정 (ADR-0002~0006) |
| 반품 (원거래 조회 → 카드 취소 → 반품 판매 → 재고 복원) | `refund.md` | 일부 결정 |
| 일마감 (POS별 마감 · 계산원 시재) | `daily-close.md` | 미작성 |
| 월마감 · 대사 (재고 이월 · 판매=결제=원장 대사 · 이상거래) | `monthly-close.md` | 미작성 |
