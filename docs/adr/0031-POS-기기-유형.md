# ADR-0031 POS 기기는 유형(판매 / 고객센터)으로 나누고 반품은 고객센터 POS에서만 한다

- 상태: 결정
- 날짜: 2026-11-23
- 관련 시스템: POS_APP, ERP
- 대체: ADR-0030

## 맥락
- ADR-0030은 반품을 반품 전용 창구에서만 하도록 ERP 기기 등록에 "반품 가능 여부"를 두었다.
- POS 기기는 ERP에 유형과 함께 등록한다 (ADR-0011, 유형 예시: 일반 계산대 / 셀프 / 키오스크).
- 반품 창구에서 반품 후 다시 판매하는 경우(재판매)가 있다.
- 카페 키오스크는 설계 보류다 (standards.md, `docs/backlog.md`).

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| 기기에 "반품 가능 여부" 체크 (ADR-0030) | 단순 | 기기 역할이 늘어날수록 체크 항목이 늘어남 |
| 기기 유형으로 역할 구분 | 유형만 보면 허용 작업이 정해짐. 새 채널(셀프 · 키오스크)을 유형으로 추가 | 유형별 허용 작업표를 관리해야 함 |

## 결정
- ERP POS 기기 등록의 **유형**은 다음 목록으로 정한다 (ADR-0011의 유형 예시를 이 목록으로 확정).

| 유형 | 허용 작업 | v1 |
|---|---|---|
| 판매 POS | 장바구니 · 결제 · 판매 확정 · POS 마감 | 포함 |
| 고객센터 POS | **반품**(원거래 조회 → 카드 취소 → 반품 판매) + **판매**(반품 후 재판매 등) · POS 마감 | 포함 |
| 셀프 계산대 | 미정 | 범위 밖 (이름만 둠) |
| 키오스크 | 미정 | 설계 보류 (이름만 둠) |

- **반품은 고객센터 POS에서만** 할 수 있다. 점포 서버는 기기 유형을 보고 허용되지 않은 작업을 거부한다.
- 반품 처리 시 **처리 담당자 사번**을 반품 판매와 감사 로그에 기록하고, 허위 반품이면 그 담당자가 책임진다. 관리자 승인은 두지 않는다 (ADR-0030 유지).

## 대가와 후속 작업
- 반품 기한, 반품 불가 상품, 반품 후 재판매 가격은 별도로 정한다.
- 고객센터 POS를 다룰 수 있는 역할은 권한 정리에서 정한다.
- 셀프 계산대 · 키오스크의 허용 작업은 각 설계 때 정한다.
