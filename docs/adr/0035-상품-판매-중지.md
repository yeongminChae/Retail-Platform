# ADR-0035 상품 판매 중지는 긴급 / 일반으로 나누고 본사는 전 점포, 매장 관리자는 자기 점포에 건다

- 상태: 결정
- 날짜: 2026-11-24
- 관련 시스템: POS_APP, ERP

## 맥락
- 상품 마스터의 원본은 ERP다 (ADR-0007). 긴급 변경 대상에 긴급 판매 중지가 있다 (ADR-0034).
- 리콜 · 위해 상품처럼 전 점포에서 막아야 하는 경우와, 특정 점포 입고분 불량처럼 그 점포만 막아야 하는 경우가 있다.

## 선택지
| 항목 | 선택지 | 장점 | 단점 |
|---|---|---|---|
| 반영 | 긴급(3분 폴링) / 일반(일배치) 구분 | 급한 것만 빠르게 | 구분 기준 필요 |
| 주체 | 본사(전 점포) + 매장 관리자(자기 점포) | 리콜과 점포 사정을 각각 처리 | 권한 범위 관리 |
| | 본사만 | 통제 단순 | 점포 사정마다 본사 요청 필요 |
| POS 차단 시점 | 스캔 시 | 단순, 결제 금액 일치 (ADR-0034) | 이미 담긴 상품은 반영 안 됨 |

## 결정
- **긴급 판매 중지**(리콜 · 위해 · 가격 오류 등): 긴급 변경으로 최대 3분 안에 반영 (ADR-0034).
- **일반 판매 중지**(단종 · 시즌 종료 등): 일배치로 다음 영업일부터 반영.
- **주체:** 본사는 **전 점포**, 매장 관리자는 **자기 점포만** 판매 중지를 건다 · 푼다. 감사 로그를 남긴다.
- **POS 차단:** 스캔 시점에 판매 중지 상품을 장바구니에 담지 못하게 한다. 이미 담긴 상품 · 결제가 시작된 판매는 그대로 진행한다 (ADR-0034).
- **반품은 막지 않는다.** 판매 중지 상품도 고객센터 POS에서 반품할 수 있다 (리콜 상품은 반품을 받아야 한다). 반품 기한 · 단순 변심 반품 불가 규칙(ADR-0032)은 그대로 적용한다.

## 대가와 후속 작업
- 긴급이라도 최대 3분, 본사 회선 장애 중에는 반영되지 않는다. 본사 연락 · 매장 진열 회수로 보완한다 (ADR-0034).
- 리콜 상품 반품에 반품 기한 · 단순 변심 불가를 예외로 둘지는 미정 (리콜은 하자 예외로 처리 가능, ADR-0032).
